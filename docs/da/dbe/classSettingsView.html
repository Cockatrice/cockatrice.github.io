Detailed Description

Settings pages with grouped left navigation and search, without any dialog chrome.

Owns the search bar, the navigation tree, the stacked settings pages and the search results view. The settings dialog only adds its own frame (buttons, titles).

Page order in the navigation, matching the order pages are added in setupUi().

Use these values instead of raw indices so reordering pages never silently breaks external callers like tab_room.cpp.
