Detailed Description

Tag slugs keyed by Scryfall oracle id and/or card name.

Loaded from Scryfall's Oracle Tags bulk data or from a user-supplied tag database. The data is import-time only: Oracle applies the slugs to the tags card property before writing cards.xml, so the client needs no tag-specific code.

Accepted inputs, auto-detected:

  • Scryfall tag objects, either a JSON array or one object per JSONL line;
  • a flat map of oracle_id (or card name) to an array of slugs;
  • a manifest object {"key": "oracle_id"|"name", "tags": { ... }};
  • JSONL rows {"oracle_id": "...", "tags": [...]} or the name equivalent.

Gzip, xz and zip inputs are decompressed transparently when the build has the matching library. Scryfall serves its bulk data as gzipped JSONL.
