◆ DeletePolicy

enum class QtUtils::DeletePolicy
strong

How clearLayoutRec() disposes of the widgets it removes.

Deferred is the safe default: deleteLater() lets a widget finish handling the event that triggered the rebuild. Use Immediate when the caller rebuilds the same layout right away and a lingering widget would be visible or otherwise in the way until the next event loop turn.

◆ findParentOfType()

template<typename T>
T * QtUtils::findParentOfType ( const QObject * obj,
bool includeSelf = false )

Returns the nearest ancestor of obj that casts to T.

Walks the QObject parent chain. QWidget::parentWidget() is the same pointer as QObject::parent() for widgets, so this also covers the common "find the parent tab, splitter or scroll area" lookups.

Parameters
objObject to start from. May be null.
includeSelfAlso test obj itself before walking upwards.
Returns
The first matching ancestor, or nullptr if there is none.
