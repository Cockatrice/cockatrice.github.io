Detailed Description

Class to provide the recording. Two behaviors :

  • Either Continuous Flush is true, the file is written after each new actions Indeed if the QtTesting/Application crashs, part of the script is written.
  • Or the file is written only when we stop the record. A simple call to the function "recordEvent" with good parameters, will start the record.
