Detailed Description

Widget-level commands for the UI tests.

pqCockatriceEventPlayer handles cards and zones inside the game scene. This player covers the rest of the client: capturing a widget as an image, dumping the paths QtTesting addresses widgets by, sizing the window, and driving item views, whose selection QtTesting's own currentChanged command cannot handle.

Commands: screenshot "<path>" grabs the addressed widget and saves it as an image. Parent directories are created, and $NAME / ${NAME} in the path expand from the environment, so the runner decides where captures land dumpTree "<path>" writes the addressed widget's subtree with the paths QtTesting addresses it by, for writing a test resize "WIDTHxHEIGHT" resizes the addressed widget's top-level window selectRow "row[/row...][,column]" selects that row of an item view, the whole row, without a mouse event clickRow "row[/row...][,column]" left-clicks the centre of that cell, so the view's own handlers run doubleClickRow "row[/row...][,column]" double-clicks it, for rows that act on double click

A tree addresses a row by the path of rows leading to it: "2/0" is the first child of the third top-level row. A click opens a collapsed path first. Rows are model rows of the addressed view, so a filtered or sorted model counts the rows it shows.
