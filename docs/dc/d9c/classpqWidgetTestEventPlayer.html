Detailed Description

Widget-level commands for the UI tests.

pqCockatriceEventPlayer handles cards and zones inside the game scene. This player covers the rest of the client: capturing a widget as an image, dumping the paths QtTesting addresses widgets by, and sizing the window.

Commands: screenshot "<path>" grabs the addressed widget and saves it as an image. Parent directories are created, and $NAME / ${NAME} in the path expand from the environment, so the runner decides where captures land dumpTree "<path>" writes the addressed widget's subtree with the paths QtTesting addresses it by, for writing a test resize "WIDTHxHEIGHT" resizes the addressed widget's top-level window
