Detailed Description

Draws the card of a CardDatabaseVisualDisplayModel row as a picture.

The delegate only paints rows the view asks for, so a grid of the whole card database stays cheap: no widget per card and no pixmap loaded for items that are off screen. Card images come from CardPictureLoader, which caches them and loads missing ones asynchronously.
