Detailed Description

Shared language metadata for localized card text and images.

Lists the language codes Cockatrice can display localized card data for and provides human-readable names. The list is shared between Oracle (which imports the selected language's card data) and the client settings UI (which offers the language choice).

◆ languageDisplayName()

QString CardLocalization::languageDisplayName ( const QString & lang)
nodiscard

Human-readable name for a language code.

Follows the same "native name (English name)" format the UI language list uses (e.g. "日本語 (Japanese)"), so the English fallback is always visible.

Parameters
langLanguage code (e.g. "de", "ja", "zhs").
Returns
The language's native name with its English name in parentheses, or the code itself if it cannot be resolved.
