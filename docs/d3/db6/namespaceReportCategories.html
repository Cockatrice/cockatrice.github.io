Detailed Description

Canonical report categories, shared by the client and the server.

This is the single source of truth for the category keys exchanged over the wire (Command_Report.category) and stored in the reports table. The server only accepts keys from this list and the client report dialog only offers keys from this list, so the two sides cannot drift apart again.
