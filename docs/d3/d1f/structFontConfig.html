Detailed Description

Per-purpose font configuration, stored as family + point size only.

Serialized to a shared fonts.toml file with a [Fonts] section, e.g.

[Fonts]
InterfaceDefault = "Inter, 10"
CardText = "Noto Serif, 12"
CardTextMinSize = 1

CardText stores family + MAX size; cardTextMinSize stores the overlay shrink-to-fit floor (omitted from TOML when 1).

◆ resolvedCardTextMinSize()

int FontConfig::resolvedCardTextMinSize ( ) const

CardText min/max resolved to what the font editor shows and a save would write: the stored values (max falling back to the CardText point size, then the default) clamped into the representable range. A seeded legacy size above the editor's maximum therefore renders at that maximum instead of at a size the editor would silently rewrite.
