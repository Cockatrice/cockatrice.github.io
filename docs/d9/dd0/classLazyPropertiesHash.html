Detailed Description

A property map that can lazily deserialize blobs to avoid loading overhead.

Properties are stored as a pre-serialized blob (cheap to load), and individual values are read straight out of that blob, so the database load and ordinary queries avoid constructing thousands of QString per card.

A full QHash<QString, QString> is only built on the first insert() or getProperties() call. Once materialized, it cannot be unmaterialized; create a new LazyPropertiesHash to return to the blob form.

◆ read()

template<typename MaterializedFn, typename BlobFn>
auto LazyPropertiesHash::read ( MaterializedFn && onMaterialized,
BlobFn && onBlob ) const
inlineprivate

Runs the accessor for the current storage form.

The common case skips the mutex once the properties are materialized. While they are still in blob form, the mutex is taken and onBlob reads the values straight out of the blob without building the hash, so ordinary queries stay allocation-light.

Parameters
onMaterializedCalled with the materialized hash when it is available.
onBlobCalled with the blob when it is still the source of truth.
Returns
Whatever the invoked accessor returns; both accessors must return the same type.
