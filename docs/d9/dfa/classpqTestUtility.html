◆ playTests() [2/2]

virtual bool pqTestUtility::playTests ( const QStringList & filenames)
virtual

Plays back the tests given by the filename(s). This is a blocking call i.e. it does not return until all the tests have been played or any of the test aborted due to failure. Returns true if the tests exist and played successfully.
