Parameters
hostThe host to clamp for

◆ getDeveloperHostCaps()

const QHash< QString, int > & DownloadSettings::getDeveloperHostCaps ( )
static

Developer-set per-host allowance ceilings (requests/second), keyed by host.

Hosts not present default to DEFAULT_HOST_REQUEST_LIMIT. An entry of UNLIMITED_HOST_QUOTA marks a host that users may still lower, but that is never throttled per host by default. Users can never raise a host's allowance above its developer cap.

◆ UNLOCKED_HOST_LIMIT_MAX

int DownloadSettings::UNLOCKED_HOST_LIMIT_MAX = 50
staticconstexpr

Upper bound offered to the user when lowering an unlocked host's allowance.

Unlocked hosts have no developer cap, so clampHostRequestLimit puts no upper bound on them; this only bounds what the settings dialog offers, and matches the widest paced allowance a user is documented to be able to hand-edit in downloads.ini. Choosing 0 below this restores the "unlimited" fast path.
