◆ setSetFilterTerms()

void CardDatabaseVisualDisplayModel::setSetFilterTerms ( const QStringList & terms)

Sets the set shorthand names of the active set filters.

With no terms every card is shown with its preferred printing. With terms every printing belonging to one of the named sets is shown instead, in term order. Rebuilds immediately when the terms change.
