Detailed Description

Tests for the deck list model's custom-zone shadow-tree helpers.

DeckListModelCustomZones centralizes every "what is / where is a custom zone" decision for the model's shadow tree: type testing, mirroring from the deck tree, name lookup, and the sort-with-custom-zones-last ordering. These tests exercise that logic directly on hand-built shadow trees, independent of the full model and card database machinery.
