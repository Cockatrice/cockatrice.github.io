Detailed Description

Parses cockatrice:// links and runs them as serialized intent chains.

Links are parsed by action (joingame/opendeck) and translated into an intent chain. Chains are queued and run one at a time: a document can hand multiple links to the window while an earlier chain still connects, and running two connect chains concurrently tears the connection down. urlChainFinished is emitted once the queue has fully drained.
