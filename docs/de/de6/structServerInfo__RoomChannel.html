◆ write_access_level

optional AccessLevel ServerInfo_RoomChannel::write_access_level = 4

Minimum privilege level required to write to the channel. When unset, writing requires the same level as reading. This allows read-mostly channels such as a developer news feed: readable by everyone, writable only by developers.
