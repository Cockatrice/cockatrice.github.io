◆ password_salt

optional string Response_PasswordSalt::password_salt = 1

Salt for the legacy password hash. Pre-challenge clients derive and send that hash from it. For migrated accounts holding a fresh legacy backup this carries the backup's salt so those clients can still log in; clients that speak challenge-response must use scrypt_salt instead when present.

optional string Response_PasswordSalt::scrypt_salt = 7

Salt of the stored scrypt verifier. Present for migrated accounts; challenge-response clients derive the verifier from this rather than from password_salt, which may carry a legacy backup salt.
