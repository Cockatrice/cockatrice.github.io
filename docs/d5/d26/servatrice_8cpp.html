QString loginLimitKey ( const QString & ipAddress,
const QString & userName )
static

Rate limiter key for one login target.

Keyed by (address, username) so a success only clears that pair's history: a guest login or a login as the attacker's own account from the same address must not wipe out another user's failure count. Lowercased so case variations of the same name share one bucket.
