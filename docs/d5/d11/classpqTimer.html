Detailed Description

pqTimer is a extension for QTimer which ensures that the timer is registered with the pqEventDispatcher. Register timers with pqEventDispatcher ensures that when tests are being played back, the timer will be ensured to have timed out if active after every step in the playback. This provides a means to reproduce the timer behaviour in the real world, during test playback.
