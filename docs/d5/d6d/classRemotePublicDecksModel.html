Detailed Description

Flat, read-only list of the public decks published by another user.

Fetches the target user's public decks via Command_DeckListOtherUser and flattens the response tree into entries carrying the preview metadata stored on the server (banner card name/provider and color identity). No deck list is downloaded until the user actually opens a deck.

Name and color-identity filtering is applied against this metadata, mirroring the Visual Deck Storage's filter semantics, so the grid can be narrowed like the local deck storage.
