Detailed Description

Replays a synthetic GameReplay through the real dispatcher. This is the only place that exercises PlayerLogic::processPlayerInfo / processCardAttachment end to end: the game state arrives as a GAME_STATE_CHANGED event and the graphics side is replaced by a small materializer that mirrors what CardZone::onCreateCardRequested does with the logic objects.

The replay is built in code rather than from a .cor file: event application is deterministic (the client never shuffles on its own for a replay), and a checked-in binary fixture would be opaque about what it asserts.
