◆ loadSentinelSvgPixmap()

QPixmap loadSentinelSvgPixmap ( const QString & resolvedPath,
IconTint tint = {},
const QSize & size = {},
IconStyle style = IconStyle::Line )

Renders a resolved theme SVG when it carries the currentColor sentinel.

Non-SVG assets and SVGs without the sentinel return a null pixmap so callers can fall back to their usual loading path (including legacy inversion).

Parameters
resolvedPathAsset path relative to the theme: search path, as returned by ThemeManager::assetPath (includes extension).
tintColor that replaces the sentinel: a palette role or a semantic application color. Defaults to WindowText.
sizePixel size to render at; an empty size uses the SVG's intrinsic size.
styleTreatment of the glyph: Line, Badge or Sticker. A treatment on a non-sentinel asset stays null, like the line path.
Returns
The recolored pixmap, or a null pixmap when the asset is not a sentinel-carrying SVG.

◆ loadThemedIcon()

QIcon loadThemedIcon ( QStringView prefix,
IconTint tint = {},
IconStyle style = IconStyle::Line )

Builds a palette-aware icon from a theme: asset.

SVG glyphs may use the currentColor sentinel. A plain QPixmap snapshot cannot follow palette changes, so this returns a QIcon whose engine resolves the sentinel from the current palette every time it is asked for a pixmap. Icons therefore stay legible when the user switches between light and dark themes without recreating any actions or buttons.

Parameters
prefixAsset prefix relative to the theme: search path, with no file extension (for example icons/search), matching themePixmap().
tintColor that replaces the sentinel: a palette role or a semantic application color. Defaults to WindowText.
styleTreatment of the glyph: Line, Badge or Sticker. Defaults to Line.
Returns
An icon that follows the application palette.
