Detailed Description

A wrapping grid of card pictures.

The view virtualizes painting: it only asks the delegate for the items that are on screen, so the whole card database can sit in the model without a widget (or pixmap) per card. Clicks and hover are reported with the exact card under the cursor, which is what the deck editor needs to add, decrement or preview a card.
