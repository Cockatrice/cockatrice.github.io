Detailed Description

Turns a text color into the ink a glyph is painted with.

A glyph is not a word. Body text is read in sentences, at a size where a 2px stroke would be unusually heavy; a glyph is a 16px mark of the same stroke, and antialiasing eats its edges, so the same color that reads as solid type reads as a thin gray line beside it. Painting icons with WindowText verbatim is what makes them recede.

The rule here is deliberately small: give the glyph a little of the theme's accent chroma, then hold it to a contrast floor against the surface it sits on. The chroma is what makes it read as an icon rather than as leftover text; the floor keeps a theme with a weak text color from producing a glyph that is not legible. Neither step invents a color: both are derived from the palette the theme already ships. An unauthored neutral family stops at the floor: the live platform palette is the only source that knows the actual scheme, so a chroma pinned in a palette file could belong to the other one.

The rule only applies to the neutral label roles. A semantic tint (AppColor::Positive, QPalette::Highlight, QPalette::Link) is a hue the call site chose on purpose, so it is left alone.

◆ disabledInk()

QColor ThemeIconInk::disabledInk ( const QColor & quiet,
const QColor & surface )

The ink a disabled glyph is painted with, given the quiet level.

A disabled glyph is the quiet ink receded further toward the surface and held to a floor below the quiet one. The palette's own disabled text is a fixed gray whose contrast varies with the surface, so on the darkest themes it out-reads the quiet level and an enabled glyph looks more disabled than a disabled one. Deriving the disabled ink from the quiet ink makes that order structural instead of incidental.

◆ forEmphasis()

QColor ThemeIconInk::forEmphasis ( const QColor & color,
const QColor & surface,
IconEmphasis emphasis )

Applies an emphasis level to an already-hued glyph color.

The three levels share one legibility floor and differ by chroma, because contrast cannot order them: on a dark surface the highest-contrast tone is the palest one, so a contrast target inverts the ladder. Primary is the most chromatic member of its family, secondary keeps the color untouched (the no-op the default needs), and quiet mutes the color to a fraction of its saturation before solving it back to the same floor.
