Detailed Description

Listens for the installer's request to close this instance gracefully.

The Windows installer cannot reach an instance whose window is hidden in the notification area with WM_CLOSE, and it must not kill a process that may hold an unsaved deck. It connects to this local socket instead and writes one line; the instance then closes the same way its own close button does - saving settings and answering its own confirmation, never bypassing it.

The socket name carries the process id, so every instance has its own and an installer that found several can ask each one. It is built by installerCloseSocketName() in tools/installer-holder-probe/installer_close_name.h; the two must stay identical.
