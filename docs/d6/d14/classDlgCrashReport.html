Detailed Description

Crash-report dialog: mock fallback or real Sentry send.

Mock mode (default): the Send path writes a redacted JSON file to the temp dir instead of uploading anything. Real mode (realSending, with a live CrashReporter): Send first folds the redacted log and the optional user note into the pending native crash event(s), then gives consent so dump, stack, log and note upload as one Sentry event; when no pending crash event exists it falls back to a standalone message event with the same attachments. Failure offers a local save instead.
