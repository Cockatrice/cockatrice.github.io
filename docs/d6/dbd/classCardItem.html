◆ doubleClickActsOnSelection()

bool CardItem::doubleClickActsOnSelection ( ) const
overrideprotectedvirtual

Whether a double-click on this item acts on the whole selection.

When true, a release without drag defers the multi-selection collapse until the double-click window passes, so a following double-click still sees every selected card. Subclasses that handle double-clicks on the selection must return true here and call cancelPendingSelectionCollapse() from their double-click handler.
