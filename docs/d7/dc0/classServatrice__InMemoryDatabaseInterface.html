Detailed Description

In-memory Server_DatabaseInterface for tests and the dev server.

Holds the little state a server needs to come up without a SQL database: registered users, the authentication outcome, the logged messages, the active user count and the game/replay id allocators. Calls that need persistence keep the interface's fail-closed defaults.
