TEST_F ( ThemeIconRenderTest ,
EmphasisTreatmentsPreviewWritesPngsWhenRequested  )

Writes the authored emphasis sheets for every shipped palette theme.

The ladder is only useful if it survives the treatment a call site chooses, so each sheet renders the same three authored levels as line glyphs, as sticker fills and as badges, at the two sizes the UI uses, on the two surfaces the contrast targets are measured against. Each family carries three glyphs, so the sheet also proves the level, not just one lucky shape. The authored tone is the top of every filled gradient, so the sheet prints that tone and the darker bottom the shape actually carries.
