Detailed Description

Badge + icon painting for the User Alts table. The match-evidence column renders as a palette-tinted pill per match type (email / client id / IP), and an IP shared by more than one other account is dimmed. Warn/ban counts gain the style's warning/critical icons when nonzero. The active column renders as a palette-tinted pill (Highlight when active, PlaceholderText when inactive, from Qt::UserRole). Selected rows and unknown content fall back to default painting.
