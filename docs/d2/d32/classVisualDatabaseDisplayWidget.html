◆ onSearchModelChanged

void VisualDatabaseDisplayWidget::onSearchModelChanged ( )
slot

Pushes the active set filters to the visual grid.

The grid's rows follow the display model's filter and sort signals on their own; this only forwards the set filters, which decide which printings the grid shows.
