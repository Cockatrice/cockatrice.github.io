bool UserDataBackup::backupAtRiskPaths ( const QStringList & sourcePaths,
const QString & backupRoot,
QStringList * backupLocationsOut,
QString * sessionDirOut = nullptr )

Copies several at-risk paths into a single timestamped session directory.

Parameters
sourcePathsfiles or directories holding user data; missing entries are skipped.
backupRootdirectory OUTSIDE the install tree that will hold timestamped backups.
backupLocationsOutreceives one entry per source that produced a backup target (including partial copies).
sessionDirOutoptionally receives the shared session directory; set to empty when nothing was backed up (all sources missing, or every copy failed outright).
Returns
true when every existing source was copied completely. A false return with a non-empty backupLocationsOut means a partial backup exists. When nothing at all could be salvaged the session directory is removed again, so a failed attempt never leaves an empty session behind that would block retries. Completeness is recorded with a marker file; see isBackupSessionComplete().

bool UserDataBackup::sessionCoversSources ( const QString & sessionDir,
const QStringList & sourcePaths )

Reports whether sessionDir was recorded as covering all of sourcePaths.

Returns
true when the session's source manifest lists every entry of sourcePaths (normalized via QDir::cleanPath, case-insensitive on Windows/macOS). Sessions without a readable manifest return false so a changed source set always triggers a fresh copy instead of reusing a backup that may not cover it.
