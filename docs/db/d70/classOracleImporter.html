◆ cancelImport()

void OracleImporter::cancelImport ( )
inline

Requests an in-flight startImport() to stop at the next set boundary.

Works by setting an atomic flag that startImport() polls between sets, so cancelImport() followed by a short waitForFinished() on the running future is safe the moment the wizard is about to be destroyed.

◆ collectForeignData()

void OracleImporter::collectForeignData ( const QString & cardKey,
const CardSetPtr & currentSet,
const QJsonObject & card,
bool collectText = true )
private

Records the first foreignData entry matching cardLang for the given card key, keeping the entry from the highest-priority set seen so far.

Multi-face cards (split, adventure, aftermath, prepare) pass collectText = false: MTGJSON emits one foreignData entry per face with the same joined name but only that face's text, so the name is collected here while the per-face texts are joined during the split-card merge.

◆ setProgressReporting()

void OracleImporter::setProgressReporting ( bool enabled)
inline

Controls whether readSetsFromByteArray() instruments the raw scan.

When enabled (the default) the raw scanner reports progress via dataReadProgress(), which an interactive wizard shows on its progress bar and a background run routes to stdout for the hosting client. Switch it off only when nothing will consume scan progress.

QMap<QString, LocalizedCardEntry> OracleImporter::splitLocalizedTexts

cardLang rules text collected for split-card names while parsing sets, applied by applyLocalizedData(). Kept apart from localizedEntries because MTGJSON emits each split face as its own card object with the joined name on every foreignData entry: names and the per-face text join have different completeness and must not overwrite each other under the same key.
