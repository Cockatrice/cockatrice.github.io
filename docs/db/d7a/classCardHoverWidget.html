◆ runModalAction()

void CardHoverWidget::runModalAction ( const std::function< void()> & action)
private

Dismisses the panel, then runs an action that opens a modal dialog.

A Qt::ToolTip window is always on top and holds the input grab, so a modal dialog opened from inside the panel lands behind it and cannot be activated. Hide the panel synchronously, then defer the action so the grab is released before the dialog's event loop starts.
