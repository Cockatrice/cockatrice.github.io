FilterMode deriveFilterMode ( const QList< const CardFilter * > & filters,
FilterMode currentMode )

Determine the mode that produced the given color filters.

Returns currentMode unchanged when that mode can still produce filters, so that a live mode is never replaced by an equally valid one. Otherwise returns the first mode that can produce them, falling back to FilterMode::Custom when none can.

Parameters
filtersThe filters on CardFilter::Attr::AttrColor and CardFilter::Attr::AttrColorIdentity.
currentModeThe mode currently selected in the UI.
