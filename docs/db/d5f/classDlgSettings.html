Detailed Description

Main application settings dialog hosting the shared SettingsView.

Thin QDialog frame around SettingsView: only the window title, the OK button and the close validation live here. All pages, navigation and search are owned by SettingsView. The dialog fills ~90% of the main window so dense pages stay visible without losing the modal adjust-and-return flow.
