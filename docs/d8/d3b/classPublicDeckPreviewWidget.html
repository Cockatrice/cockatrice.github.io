Detailed Description

A preview tile for a public deck published by another user.

Renders the banner card picture (looked up by name/provider in the card database) with the deck name overlaid, the color identity, the deck's tags (read-only) and its upload time, all from the metadata the server stores for the deck, so no deck list is downloaded until the user actually opens the deck. Double-clicking the banner requests opening it.
